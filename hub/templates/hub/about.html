About CourseShare Hub

CourseShare Hub is a centralised, searchable platform where students upload, organise, and revisit course materials together.

Course files usually live scattered across email, group chats, Brightspace, personal folders, and cloud drives. CourseShare Hub brings them into one student-friendly place: browse and search public resources as a guest, or register to upload, comment, and save favourites.

Built with

Django — models, class-based views, forms, auth, sessions & cookies Bootstrap 5 + Lucide icons for the interface SQLite with JSON fixtures for initial data

Made for COMP-8347 — Internet Applications and Distributed Systems.
